# 拼豆工作室 · 作品墙投稿

这是「拼豆工作室」作品墙的**投稿审核队列**（内测）。

## 怎么投稿

1. 打开 [拼豆工作室](https://kakarorkaka.github.io/pindou-studio/)，做一张图纸。
2. 点「导出图纸 → 发布到作品墙」。
3. 确认权利声明，点「提交审核」。
4. 会自动打开一个新 Issue，内容已填好；直接提交即可。
5. 审核通过后，作品会出现在作品墙（1–3 天）。

## 审核标准

- 图纸完整可拼，色号 / 品牌 / 颗数准确
- 不侵犯他人著作权；二创请注明来源，且仅限免费分享
- 实拍成品是加分项，但不是必须
- 同一作品请勿重复提交

## 权利声明

提交即表示：你拥有该图案的权利，或已获得权利人授权，并同意在拼豆工作室作品墙展示。收到侵权投诉并经核实的作品会被下架。

## 说明

- 内测期间免费。
- 作品墙是精选制，未通过不等于作品不好，可能只是不适合当前主题。
- 本仓库只用于投稿与审核，不存放站点代码。
